# Dataset Registry

Jangan simpan raw dataset besar langsung di Git repository.

Dokumentasikan setiap versi dataset di sini dengan:

- dataset name / version
- source
- storage location
- number of images
- Cavendish cultivar confirmation
- collection conditions
- annotation format
- train/validation/test split
- license / usage restrictions

Recommended metadata fields:

```text
image_id
plant_id
bunch_id
flowering_date
photo_date
days_after_flowering
maturity_stage
maturity_score
harvest_date
postharvest_maturity
```
